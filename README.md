# KrakenKey Homebrew tap

Homebrew casks for [KrakenKey](https://krakenkey.io) tools. Works on macOS and Linux.

```bash
brew install krakenkey/tap/krakenkey
```

Update with `brew upgrade krakenkey`. The cask installs the `krakenkey` CLI from the [KrakenKey/cli](https://github.com/KrakenKey/cli) GitHub release and checks it against the release checksums.

The casks in `Casks/` are written by the CLI's release workflow. Don't edit them by hand; open an issue on [KrakenKey/cli](https://github.com/KrakenKey/cli/issues) instead.
